# AeroGuide ✈️ — AI-Powered Airport & Flight Assistant

AeroGuide is an interactive airport navigation and real-time flight tracking dashboard. It provides passengers with live flight updates, gate and terminal guidance, route mapping, and an integrated AI assistant to optimize their airport experience.

---

## ✨ Features

* **Real-Time Flight Tracking:** Live flight details including gate, terminal, status updates, and auto-calculated boarding countdowns.
* **Smart Airport Assistant:** Integrated AI chatbot to help passengers locate lounges, gates, amenities, and security check lines.
* **Interactive Terminal Map:** Visual guidance and interactive markers for quick airport navigation.
* **Multi-Language Support:** Instant internationalization (i18n) support for global travelers.
* **Robust Fallback Engine:** Graceful fallback mechanisms handling rate-limited or missing third-party flight API data without crashing the UI.

---

## 🛠️ Tech Stack

### Frontend
* **Framework:** React 18 (TypeScript) + Vite
* **Styling:** Tailwind CSS + Shadcn UI
* **Animations:** Framer Motion
* **Icons:** Lucide React

### Backend
* **Language/Framework:** Java (Spring Boot)
* **Flight API:** Aviationstack API / Custom Real-Time Flight Wrapper
* **Deployment:** Render
